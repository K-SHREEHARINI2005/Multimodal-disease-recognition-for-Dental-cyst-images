# Multimodal-disease-recognition-for-Dental-cyst-images
It focuses on detecting and localizing Radicular Cysts (RC) and Dentigerous Cysts (DC) using the DOLCHID CBCT dataset.
CBCT-Based Dental Cyst and Lesion Localization is a deep learning-based research project developed to identify and localize dental cysts and lesions from Cone-Beam Computed Tomography (CBCT) images using the DOLCHID dataset. The primary focus of this project is on two types of dental cysts: Radicular Cysts (RC) and Dentigerous Cysts (DC), while Keratocystic Odontogenic Tumors (KCOT) and Ameloblastoma (AME) are excluded from the current study. The project aims to develop an automated lesion localization workflow that analyses CBCT images, extracts relevant visual features, identifies lesion presence, and predicts the approximate spatial location of lesions using bounding boxes. The workflow begins with volumetric CBCT images and their corresponding ground-truth labels available in NIfTI formats (.nii and .nii.gz). These volumes undergo preprocessing and slice extraction to prepare individual two-dimensional images and their corresponding lesion masks for model development. The original CBCT images retain their grayscale intensity information, while the corresponding lesion masks are converted into binary masks, where pixel value 1 represents the lesion region and pixel value 0 represents the background. Using these binary masks, the coordinates of all lesion pixels are extracted to calculate the minimum and maximum X and Y coordinates (x_min, y_min, x_max, y_max). These coordinates are used to generate ground-truth bounding boxes, and their width and height are calculated using the inclusive-coordinate convention. The bounding-box coordinates are subsequently normalized and prepared as localization targets for model training. Image-mask correspondence is verified through dataset inspection, file validation, dimension checking, and annotation validation to maintain consistency between input images and their ground-truth labels. For deep learning-based localization, the project uses a ResNet-18 architecture as the feature extraction backbone, integrated with a Convolutional Block Attention Module (CBAM) to refine the extracted features through channel attention and spatial attention mechanisms. Channel attention emphasizes informative feature channels, whereas spatial attention assigns importance to relevant spatial locations within the feature maps. The refined features are passed through fully connected layers connected to two prediction branches: a classification branch that predicts whether a lesion is present or absent and a bounding-box regression branch that predicts the lesion's normalized centre coordinates, width, and height. The model is trained using a combined loss function consisting of Binary Cross Entropy with Logits Loss for lesion classification and Smooth L1 Loss for bounding-box regression, with a weighting factor applied to the localization loss. During training, the predicted outputs are compared with the ground-truth labels and bounding-box coordinates generated from the binary masks, allowing the network to learn lesion-related features and approximate lesion locations. The project also includes evaluation and visualization procedures to compare predicted bounding boxes with ground-truth annotations and assess localization performance using suitable metrics such as Intersection over Union (IoU), along with classification metrics such as accuracy, precision, recall, and F1-score where implemented. Python is used for medical image preprocessing, data handling, model development, training, and evaluation, while Java utilities support selected dataset inspection, image-label validation, bounding-box generation, and visualization operations. Overall, this project combines medical image processing, deep learning, attention mechanisms, and bounding-box-based localization to develop a research prototype for identifying and localizing dental cysts in CBCT images. It is intended for academic research and experimentation and is not a clinically validated diagnostic system.
